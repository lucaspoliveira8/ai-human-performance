# AI Human Performance

This repository contains applied artificial intelligence and machine learning projects focused on:

- Human performance modeling
- Decision-making under stress
- Engineering-driven AI applications
- Reinforcement learning and optimization

The goal of this portfolio is to explore how AI can model, predict, and optimize human behavior and performance in high-stakes environments such as engineering systems, aerospace, motorsport, and complex decision-making scenarios.

---

## Project Roadmap

### Project 01 — Human Performance Under Stress
Model human performance degradation and decision quality under increasing cognitive and physical stress using machine learning.

Status: In progress

### Project 02 — Reinforcement Learning for Decision Optimization
Train a reinforcement learning agent to optimize decisions under constraints and uncertainty.

Status: Planned

### Project 03 — Applied AI for Engineering Systems
Apply machine learning to predict or optimize an engineering-related system.

Status: Planned
