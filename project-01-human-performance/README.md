# Project 01 — Human Performance Under Stress

## Objective
Model how human performance changes under increasing levels of stress using machine learning.

This project explores:
- Performance degradation
- Decision accuracy
- Stress-performance relationships

## Problem Statement
Humans operating in high-pressure environments often experience performance drops as stress increases.  
The objective is to model this relationship using synthetic or real-world inspired data.

## Approach
- Generate or load a dataset simulating stress vs performance
- Perform exploratory data analysis
- Train a regression model
- Evaluate performance trends

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
